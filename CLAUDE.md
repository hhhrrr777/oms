# Agent skills 配置

供 Matt Pocock 的 engineering skills 读取的 per-repo 配置索引。

## Agent skills

### Issue tracker

Issues 存放在本 repo 的 GitHub Issues,通过 `gh` CLI 读写。See `docs/agents/issue-tracker.md`.

### Triage labels

使用默认五个 canonical triage labels:`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context:repo 根目录一个 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.
